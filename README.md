# arsalanghogari.com

The personal portfolio site of Arsalan Ghogari, live at
[arsalanghogari.com](https://arsalanghogari.com).

A single self-contained `index.html` that showcases work, projects, and contact
information, with a downloadable résumé. Every image is embedded directly in the
page, so the site is entirely self-contained.

## Contents

- `index.html` — the entire site
- `resume.pdf` — résumé linked from the hero
- `CNAME` — custom domain configuration for arsalanghogari.com
